# Archive

This directory contains legacy and scratch files preserved from earlier development iterations:

- **`Project.cpp`**: An earlier iteration of the IPFS simulation before additional features (B-tree indexing expansions, OpenCV image hashing and viewing, machine status toggling, and file migration) were finalized.
- **`temp.cpp`**: A standalone scratch file used for prototyping arbitrary-precision power calculations (`FindingPower`) with the `BigInt` class.
